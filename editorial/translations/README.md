# Traductions des neuf nouveaux articles

Les fichiers anglais, portugais du Brésil et espagnol contiennent les titres, sous-titres et textes complets des neuf articles publiés le 2 novembre 2026. Ils conservent les paragraphes, les sections, les dates, les chiffres et les réserves factuelles de la version française. Les sources restent partagées par les versions de chaque article.

La migration 021 enregistre ces 27 traductions éditoriales dans le mécanisme existant de cache par version. Elle utilise la version réelle de la base : les horodatages de déploiement local et de production ne sont pas supposés identiques. Une empreinte du titre, du sous-titre et du corps français empêche d’associer une traduction à un article modifié depuis sa préparation. Une traduction existante n’est pas remplacée. Les articles et traductions antérieurs sont conservés.

Si un article est modifié ultérieurement, ses traductions doivent être révisées pour cette nouvelle version, via le CMS ou le workflow de traduction existant. Un texte français affiché temporairement sur une autre version linguistique doit être clairement signalé par un message rédigé dans la langue de la page, sans exposer de texte d’interface en créole.

Les tests vérifient les pages complètes et leurs métadonnées, la disponibilité dans les quatre langues, les messages de repli et la conservation des traductions déjà présentes. Une vérification HTTP du site public complète la validation après déploiement.
